# AgricultureClaw

Agriculture management for [ERPClaw](https://github.com/avansaber/erpclaw). Land parcels, crop planning, field operations, harvest tracking, livestock management, and cooperative accounting. 63 actions across 6 domains.

## Features

- **Land Management** -- parcels, soil tests, land use records, utilization reports
- **Crop Planning** -- crop types, planting plans, growth stages, seed lots, crop rotation
- **Field Operations** -- scheduled operations, scouting reports, irrigation logs, chemical applications
- **Harvest Tracking** -- harvest records, storage bins, quality grading, yield analysis
- **Livestock** -- animal records, health events, feeding logs, weight tracking, herd summaries
- **Cooperative Accounting** -- member registration, delivery tickets, patronage calculations, pool accounts

## Installation

Requires [ERPClaw](https://github.com/avansaber/erpclaw) core.

```
install-module agricultureclaw
```

## Quick Start

```
"I'm starting a farm -- set me up for agriculture"
```

The bot will install AgricultureClaw and guide you through registering parcels, planning crops, and tracking livestock.
